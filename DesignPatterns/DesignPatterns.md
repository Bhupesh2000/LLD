Design Patterns - 
A general, reusable solution to a common problem within a specific context in software design.
Patterns are blueprints that can be applied in multiple situations but they are not direct pieces of code.
Focus on object interactions, system architecture and how classes/objects communicate.

Benefits - 
1. Code Reusibility - Patterns provide proven solutions that can be applied in multiple projects
2. Maintainability - Encourage clean understandable and structured code which is easier to maintain and extend.
3. Communication- Acts as a common language between developers, improving communication and understanding.
4. Scalability - Helps in structuring code to support a future scaling with fewer refactors.
5. Efficiency - Avoids reinventing the wheel by using practices that are well tested and are widely accepted solutions.
